## این بخش برای کیست؟

همه نقش‌ها — مخصوصاً کسی که ربات را روی سرور نصب می‌کند یا اولین‌بار وارد وب‌پنل می‌شود. بعد از نصب، مالک معمولاً ویزارد را کامل می‌کند؛ بقیه نقش‌ها بیشتر برای ورود روزانه به همین صفحه مراجعه می‌کنند.

## نصب سریع

روی اوبونتو ۲۲٫۰۴ یا جدیدتر (نسخهٔ S-UI، کانال **پایدار / main**):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/alirezasj7/PGClockBot-SUI/main/install-sui.sh)
```

دستور، مخزن فورک را دریافت و نصب را شروع می‌کند. پورت پیش‌فرض `9000` و حالت نصب
بدون دامنه/SSL است؛ بعد از بالا آمدن سرویس، ویزارد اولیه را در مرورگر کامل کنید.

برای پیش‌نسخهٔ آزمایشی از گزینهٔ **`2) Install dev`** یا این یک‌خطی استفاده کنید:

```bash
PGCLOCK_CHANNEL=dev bash <(curl -fsSL https://raw.githubusercontent.com/alirezasj7/PGClockBot-SUI/dev/get.sh) install-dev
```


### مثال واقعی

فرض کنید IP سرور شما `203.0.113.10` است:

1. نصب را تمام کنید.
2. بروید به `http://203.0.113.10:9000/`
3. در ویزارد: یوزر/رمز وب، توکن ربات تلگرام، آدرس S-UI، توکن API v2 و آدرس Subscription با IP را پر کنید.
4. **Finish** بزنید و با همان یوزر وارد پنل شوید.
5. پاورقی منو را ببینید: برای حساب ریشه معمولاً برچسب **مالک** است (نقش نشست همچنان `admin`).

:::info
پورت پیش‌فرض وب‌پنل **۹۰۰۰** است. اگر پشت فایروال یا کلود هستید، این پورت باید باز باشد (یا از ریورس‌پراکسی با دامنه استفاده کنید).
:::

## اگر پروژه از قبل روی سرور هست

```bash
cd PGClockBot-SUI
bash get.sh
# یا
bash pgclock.sh
```

آپدیت: منو → **`3) Update main`** (یا **`4) Update dev`** اگر روی کانال توسعه هستید). فایل `.env` و دیتابیس حفظ می‌شوند؛ آپدیت دستی با کپی‌پیست پوشه توصیه نمی‌شود.


## ویزارد اولیه چه چیزهایی می‌پرسد؟

معمولاً این‌ها را یک‌بار تنظیم می‌کنید:

| مورد | چرا لازم است؟ |
|------|----------------|
| یوزر و رمز وب | ورود به پنل مدیریت |
| توکن ربات | اتصال به تلگرام |
| آدرس و اعتبار پاسارگارد | ساخت سرویس VPN بعد از خرید |
| تنظیمات پایه فروشگاه | شروع کار بدون پنل خالی |

اگر ویزارد را نیمه‌کاره رها کنید، ممکن است فقط با لینک یک‌بارمصرف یا از خود سرور قابل باز شدن باشد.

## اولین کار بعد از نصب

1. در **تنظیمات ربات** (`/settings`) متن خوش‌آمد و دکمه‌های منو را ببینید و در صورت نیاز فارسی‌سازی کنید.
2. یک **پلن** بسازید و به تمپلیت/گروه پاسارگارد وصل کنید.
3. روش پرداخت (مثلاً کارت‌به‌کارت) را در تنظیمات پرداخت پر کنید.
4. در تلگرام به ربات `/start` بزنید و یک خرید آزمایشی بگیرید.
5. رسید آزمایشی را از [مدیریت مالی](../finance/index.html) تأیید کنید و ببینید سرویس ساخته می‌شود.
6. اگر منو محدود به نظر می‌رسد، [نقش‌ها](../roles/index.html) را بخوانید — معمولاً دسترسی است نه باگ.

### چک سلامت سریع

```bash
bash pgclock.sh status
bash pgclock.sh service
curl http://127.0.0.1:9000/health
```

اگر `health` جواب ندهد، اول سرویس و پورت را درست کنید؛ بعد سراغ تنظیمات فروشگاه بروید.

:::error
**مشکل:** صفحهٔ وب باز نمی‌شود یا Timeout می‌دهد.

**علت رایج:** فایروال پورت ۹۰۰۰ را بسته، یا سرویس بالا نیست.

**راه حل:**
```bash
bash pgclock.sh service
curl http://127.0.0.1:9000/health
sudo ufw allow 9000/tcp
```
:::

:::error
**مشکل:** ویزارد می‌گوید فقط با لینک یک‌بارمصرف.

**علت رایج:** از اینترنت بدون توکن gate باز کرده‌اید.

**راه حل:** روی سرور اول وارد پوشهٔ نصب شوید، بعد وضعیت را بگیرید:

```bash
cd "$(cat /usr/local/lib/pgclockbot/install_root)"
bash pgclock.sh status
```

یا از هر جا: `pgclock status`. لینک کامل را کپی کنید، یا از خود سرور با `127.0.0.1` باز کنید.
:::

:::tip
قبل از هر آپدیت بزرگ، از [تنظیمات وب پنل](../settings-panel/index.html) بکاپ بگیرید. بکاپ/آپدیت/SSL فقط برای مالک در تب‌های `/settings` است؛ نقش‌های دیگر برای رمز حساب از `/security` استفاده می‌کنند.
:::
